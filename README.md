# Gayathri Ravinderreddy - Portfolio Website

A modern, responsive React portfolio website showcasing my projects, skills, and experience as a Software Engineer Intern.

## Features

- 🎨 Modern and clean UI design with soft colors
- 📱 Fully responsive design for all devices
- ⚡ Smooth scrolling navigation
- 🎯 Interactive sections: Home, About, Skills, Projects, Experience, and Contact
- 💼 Showcase of projects and work experience
- 📧 Contact form with email integration

## Technologies Used

- React 18.2.0
- CSS3 (with modern features like Grid, Flexbox, and animations)
- HTML5

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd gayathri-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.

## Customization

### Update Personal Information

1. **Contact Information**: Edit `src/components/Contact.js` to update email, LinkedIn, and GitHub links.

2. **About Section**: Modify `src/components/About.js` to update your personal description.

3. **Projects**: Update the projects array in `src/components/Projects.js` with your actual projects.

4. **Skills**: Adjust the skills array in `src/components/Skills.js` to match your skill set.

5. **Experience**: Update `src/components/Experience.js` with your work experience details.

### Color Scheme

The primary color is `#6B73FF` (a soft purple/blue). You can customize colors by updating the CSS variables or directly modifying the color values in the component CSS files.
